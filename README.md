# Amazon Picks Website

A lightweight product-curation and affiliate website prototype built with HTML and CSS. It presents selected product recommendations, product descriptions, and links that direct visitors to Amazon.

## Pages and assets

| File | Purpose |
|---|---|
| `index.html` | Home page with featured product sections |
| `products.html` | Product feature and review content |
| `blog.html` | Blog page placeholder |
| `contact.html` | Contact page placeholder |
| `styles.css` | Shared site styling |

## Technologies

HTML and CSS.

## Project note

This repository is a front-end website prototype. Before using it as a live affiliate site, replace any placeholder affiliate tracking IDs, verify product details and links, and add the required affiliate disclosure and privacy information.
